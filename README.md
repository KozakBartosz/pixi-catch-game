# Pixi Catch Game

Minimalne środowisko dla gry typu „łapanie spadających przedmiotów”.

## Project documentation

- [Agent instructions](AGENTS.md): entry point and working conventions for agents.
- [Decision log](docs/decisions.md): adopted decisions, rationale, and open choices.
- [Implementation plan](docs/plan.md): gameplay requirements and architecture.
- [Technology stack](docs/stack.md): runtime constraints, current tooling, and verification gaps.
- [Implementation tasks](docs/tasks.md): ordered work and acceptance criteria.

## Wymagane wersje

- Node.js `16.16.0`
- npm `8.11.0`

## Uruchomienie

```bash
nvm use
npm install
npm start
```

## Sprawdzenie wersji

```bash
node --version
npm --version
```
